
# ☕ Java Fundamentals

Welcome to the **Java Fundamentals** section of my Object-Oriented Programming (OOP) repository.

This folder contains beginner-friendly Java programs covering the basic concepts of Java programming, including variables, data types, input and output, operators, control flow statements, loops, and important Java keywords.

The purpose of this section is to build a strong foundation in Java before moving on to Object-Oriented Programming concepts.

---

## Learning Objectives

- Understand the basic structure of a Java program.
- Learn variables, data types, and operators.
- Take user input and display output.
- Use conditional statements to make decisions.
- Understand different types of loops.
- Learn how `break` and `continue` work.
- Understand important Java keywords.
- Develop basic programming logic and problem-solving skills.

---

## Topics Covered

- Java Basics
- Input and Output
- Operators
- Control Flow Statements
- Loops
- Jump Statements
---

## Requirements

- Java Development Kit (JDK)
- IntelliJ IDEA, Eclipse, or Visual Studio Code
- Basic computer knowledge

**Recommended Java Version:** Java 25 (LTS)

The programs use standard Java features and can run on other compatible JDK versions as well.

---

## ▶️ How to Run

### Step 1: Check Java Installation

Open the terminal or command prompt and run:

```bash
java -version
javac -version
```

### Step 2: Compile a Program

For example, compile `HelloWorld.java`:

```bash
javac HelloWorld.java
```

### Step 3: Run the Program

```bash
java HelloWorld
```

**Note:** Run these commands from the directory containing the Java source file.

You can also open the project in IntelliJ IDEA and click the Run button beside the `main()` method.
