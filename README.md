# Object-Oriented Programming (OOP) in Java

Welcome to my **Object-Oriented Programming (OOP) in Java** repository!

This repository contains beginner-friendly Java programs, examples, and practice problems covering the fundamental concepts of Object-Oriented Programming. It is designed to help students learn Java step by step, understand OOP principles, and build a strong programming foundation.

The examples are organized by topic to make learning, revision, and practice easier.

---

## About This Repository

- **Language:** Java
- **Programming Paradigm:** Object-Oriented Programming
- **Java Version:** Java 25 (LTS)
- **IDE:** IntelliJ IDEA / Eclipse / VS Code
- **Purpose:** Learning, practice, revision, and academic preparation

## Learning Objectives

- Understand Java syntax and programming fundamentals.
- Learn the four pillars of Object-Oriented Programming.
- Develop reusable and maintainable code.
- Understand how classes and objects work.
- Practice inheritance, polymorphism, abstraction, and encapsulation.
- Learn exception handling, collections, and file handling.
- Improve problem-solving and programming skills.

# 💻 Sample Java Program

```java
public class Main {

    public static void main(String[] args) {

        System.out.println("Welcome to OOP in Java!");

    }
}
```

### How to Run

1. Install a compatible JDK.
2. Create a Java source file named `Main.java`.
3. Write the program and save the file.
4. Compile the program:

```bash
javac Main.java
```

5. Run the compiled program:

```bash
java Main
```

# Requirements

- Java Development Kit (JDK)

**Recommended Java version:** Java 25 LTS. You can also use another compatible JDK if the examples do not require newer language features.

---

# Learning Approach

The recommended learning sequence is:

1. Learn Java syntax and fundamentals.
2. Practice methods, arrays, and strings.
3. Understand classes, objects, and constructors.
4. Master encapsulation, inheritance, polymorphism, and abstraction.
5. Practice interfaces and class relationships.
6. Learn exception handling, generics, and collections.
7. Explore file handling and advanced concepts.
8. Apply your knowledge through projects and problem-solving.
